# ⚡ Kronos Auto-Trading

Веб-приложение **автоторговой системы криптовалютой** на базе foundation-модели **Kronos** (GPT для финансовых OHLCV-свечей) + гибридного сигнального слоя (Kronos + классические индикаторы + математика рисков).

**Режимы:** paper trading (тестовый, стартовый капитал **$100**) и **live** (реальные деньги через API-ключи биржи). Переключение — в шапке сайта.

## ⚙️ Что делает приложение

### Торговый цикл (автоматически, по APScheduler)

На закрытии каждой свечи (1h — каждый час, 4h — каждые 4 часа) для каждой включённой монеты:

1. **Загрузка данных** — CCXT → Binance, обновление последней свечи + удаление старых (pruning)
2. **Индикаторы** — RSI(14), MACD, EMA(20/50), ATR(14), Bollinger, ADX(14)
3. **Kronos прогноз** — N свечей вперёд (вероятностный, с кэшем)
4. **Композитный сигнал** S_entry ∈ [0,1] — ансамбль из 5 суб-сигналов
5. **Проверка выхода** по открытым позициям (take-profit, trailing-stop, ATR-stop, signal-reversal, time-stop)
6. **Вход** если авто-режим ВКЛ и S_entry ≥ 0.65 и expected_pnl > 0
7. **Обновление equity** кривой

### Ручное управление

- Кнопка **«Авто ВКЛ/ВЫКЛ»** — включает/выключает автоматическую торговлю по монете
- Кнопка **«Обновить»** — принудительный тик (пересчёт сигнала)
- Кнопка **«Купить»** — ручная покупка (открывает позицию по текущему сигналу)
- Кнопка **«Продать»** — ручная продажа (закрывает позицию)

## 🧠 Математическая модель

### Порог безубыточности (план 4.1)
```
round_trip_cost = 2 × (commission 0.1% + slippage 0.05%) = 0.3%
min_expected_move = 0.3% + margin_of_safety 0.3% = 0.6%
```
Сделка открывается только если прогнозируемое движение ≥ 0.6%.

### Композитный сигнал входа (план 4.3)
```
S_entry = 0.23·f_trend     (EMA20 > EMA50, наклон тренда)
        + 0.27·f_kronos    (pred_return ≥ min_move AND slope > 0)
        + 0.18·f_momentum  (MACD гистограмма / бычий импульс)
        + 0.13·f_rsi       (RSI в зоне силы [40, 70])
        + 0.09·f_pullback  (откат к EMA20)
        + 0.10·f_news      (сентимент новостей ∈ [0, 1])

Вход: S_entry ≥ 0.55..0.65 AND pred_return ≥ 0.6% AND ADX ≥ 15 AND expected_pnl > 0
```
*(Поддерживаются как **LONG**, так и **SHORT** позиции с зеркальным расчетом сигналов и риска).*

### Размер позиции (план 4.5)
Fixed-Fractional + ATR: риск 1% капитала на сделку, стоп-лосс = 1.5 × ATR, тейк-профит = 3.0 × ATR (R/R ≈ 2.0).

## 📰 Новостной индикатор настроения (LLM + RSS)

В торговую стратегию интегрирован анализ новостного фона монет в реальном времени:
1. **Источники новостей**:
   - **Встроенный RSS (бесплатно, без ключей)**: автоматический сбор свежих новостей из CoinTelegraph, CoinDesk, Decrypt и Bitcoinist.
   - **Tavily Search API (опционально)**: глубокий поиск новостей по доменам. При исчерпании лимита срабатывает встроенный Circuit Breaker, мгновенно переключая систему на RSS без задержек.
2. **LLM-анализ (Groq / Qwen)**:
   - Анализ свежего новостного фона через бесплатный высокоскоростной API **Groq** (`qwen/qwen3.8-27b`).
   - Возвращает сентимент рынка $\in [-1.0, +1.0]$, уверенность (confidence), ключевые события и резюме на русском языке.
   - Поддерживает автоматический каскад резервных моделей при недоступности API.
3. **Отказоустойчивость**:
   - Если LLM недоступна или ключи не заданы, `f_news = 0.5` (нейтрально) — торговый цикл и аналитика продолжают работать в штатном режиме без сбоев.

## 💾 Управление данными (план 6)

- **При запуске:** скачивается 2000 свечей для каждой монеты (cold start)
- **При перезапуске:** проверка глубины и свежести, дозагрузка дельты
- **В процессе:** на каждом тике добавляется 1 свежая свеча, старые (> 2200 свечей) удаляются
- **БД не растёт:** скользящее окно хранения, регулярный pruning

Поддерживаемые монеты (по умолчанию):
`BTC/USDT, ETH/USDT, BNB/USDT, SOL/USDT, XRP/USDT, ADA/USDT, DOGE/USDT, AVAX/USDT, LINK/USDT, MATIC/USDT`

## 🔧 Настройка (.env)

Все параметры можно менять в `.env` (см. `.env.example`). Ключевые:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `PAPER_INITIAL_BALANCE` | 100 | Стартовый капитал (USDT) |
| `WALLET_ENCRYPTION_KEY` | (пусто) | Ключ Fernet для шифрования секретов кошельков. Если пуст — производный от APP_PASSWORD |
| `LIVE_AUTO_ENABLED` | false | Разрешить авто-торговлю реальными деньгами |
| `ENTRY_THRESHOLD` | 0.65 | Порог S_entry для входа |
| `RISK_FRACTION` | 0.01 | Риск на сделку (1% equity) |
| `ATR_K_STOP` | 1.5 | Множитель ATR для стоп-лосса |
| `ATR_K_TAKE` | 3.0 | Множитель ATR для тейк-профита |
| `MAX_HOLD_PERIODS` | 48 | Time-stop (свечей) |
| `KRONOS_DEVICE` | cuda | cuda \| cpu |
| `KRONOS_PRED_LEN` | 8 | Горизонт прогноза (свечей) |

Изменения вступают в силу после перезапуска приложения.

## 💰 Live-режим (реальные деньги)

Приложение поддерживает **два режима**, переключаемых кнопкой в шапке сайта:

| Режим | Деньги | Ордера | Авто-торговля |
|---|---|---|---|
| **Paper** 📝 | Виртуальные ($100) | Симуляция (fee + slippage) | Включается кнопкой на монете |
| **Live** 💰 | Реальные (с биржи) | Настоящие рыночные ордера через CCXT | Требует доп. разрешения |

### Как это работает

1. **Кошелёк** — привязка API-ключей биржи (api_key + api_secret). Добавляется в
   разделе **Настройки → Кошелёк биржи**. Ключи валидируются реальным запросом
   баланса. `api_secret` хранится в БД **зашифрованным** (Fernet).
2. **Переключение режима** — кнопки `📝 Paper | 💰 Live` в шапке. Данные обоих
   режимов живут параллельно (раздельные сессии, поле `Session.mode`).
3. **Реальные ордера** — кнопки Купить/Продать в live-режиме ставят настоящие
   рыночные ордера. Цена/qty/fee берутся из ответа биржи.
4. **Баланс** — в live cash синхронизируется с реальным свободным USDT на бирже.

### Безопасность

- 🔒 Авто-торговля реальными деньгами **выключена по умолчанию**
  (`LIVE_AUTO_ENABLED=false`). Включается отдельной кнопкой в Настройках.
- 🔒 `api_secret` шифруется Fernet, не хранится и не логируется в открытом виде.
- ⚠️ Шорт в live-режиме недоступен (spot-биржа не поддерживает маржу).
- ⚠️ Яркие предупреждения в UI при работе с live-режимом.

### Настройка live-режима

1. Создайте API-ключи на Binance (только spot-торговля, без вывода средств).
2. Откройте **Настройки → Кошелёк биржи**, добавьте ключи.
3. Переключитесь в режим **Live** кнопкой в шапке.
4. (Опц.) Включите авто live в Настройках, если доверяете системе.

## ⚠️ Риски (честно)

- Kronos ≠ гарантия прибыли — поэтому ансамбль + комиссионный фильтр + risk/reward обязательны
- Только spot long — в медвежьем рынке система уходит в кэш (это защита)
- Это прототип: SQLite, без многопользовательности, упрощённая отказоустойчивость
- Live-режим реализован (реальные ордера через биржу), но требует осторожности: реальные деньги под риском
